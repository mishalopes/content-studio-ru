# Content Studio RU

Русскоязычный агентский навык для создания контента от идеи до готовых файлов.
Сценарии, Reels, карусели, Stories, монтаж, субтитры, анимация и анализ публикаций
в одном пакете с общим маршрутом работы.

Сборка и адаптация - **Misha Lopes**. Для адаптированных материалов сохранены авторство и лицензии; внешние
видеопроекты подключаются отдельно через официальные источники.

## Возможности

| Направление | Что входит |
| --- | --- |
| Сценарии | 26 приёмов начала ролика, отдельные речь, экранный текст и план кадров |
| Русский текст | Подсчёт слов с кириллицей, оценка времени речи, хештеги, предпросмотр подписи |
| Контент | Чек-листы профиля, каруселей, Stories и недельного плана |
| Аналитика | Сравнение просмотров с медианой, сохранения и пересылки на охват, пропуски и размер базы |
| Remotion | Русский маршрут работы и ссылки на официальные инструкции |
| HyperFrames | Маршрут для HTML-композиций и ссылка на отдельный движок |
| Lemo Opuscar | Выбор художественной техники, ссылка на внешний каталог 66 стилей |
| MG Styles 15 | Маршрут работы с внешними 15 рецептами motion design |
| Серии Reels | Процесс подготовки 50 коротких роликов и проверка готовых MP4 |
| Публикация | Работа через доступный коннектор, например Metricool, с проверкой аккаунта и очереди |

Главное руководство и русские адаптации находятся в `skills/content-studio-ru`.
Движки, их установщики и каталоги стилей в пакет не включены. Инструкции помогают
выбрать и использовать нужный инструмент. Внешние руководства могут быть
на английском или китайском; авторский контент создаётся на выбранном языке.

## Установка

В агенте с поддержкой Agent Skills можно дать такое поручение

```text
Установи навык content-studio-ru из
https://github.com/mishalopes/content-studio-ru
Главный файл находится в skills/content-studio-ru/SKILL.md.
Используй штатный механизм установки моего агента.
```

В среде с CLI `skills` можно выбрать целевого агента при установке

```bash
npx skills add mishalopes/content-studio-ru --skill content-studio-ru
```

Для ручной установки скопируйте целиком папку `skills/content-studio-ru` в папку
навыков вашего локального агента. Сохраните папки `references`, `scripts`, `licenses`
и файлы лицензий вместе с `SKILL.md`. Если одноимённая папка уже существует,
сначала сохраните свои изменения и сравните версии.

Установка персонального навыка в ChatGPT зависит от доступного в аккаунте
механизма навыков. Сам по себе обычный текстовый чат может использовать инструкции,
а выполнение скриптов и создание MP4 требуют среды исполнения.

## Начало работы

Дайте агенту исходники, цель, аудиторию и референс. Профиль автора можно оформить
по `references/voice-template.md` и хранить внутри своего проекта.

```text
Используй content-studio-ru. Вот моё видео. Собери вертикальный ролик
с русскими субтитрами и обложкой. Голос и визуал возьми из моего референса.
Дай готовый MP4.
```

```text
Используй content-studio-ru. Я фотограф, моя аудитория - владельцы кафе.
Предложи три разных начала ролика про съёмку еды на телефон.
Не придумывай мои кейсы и результаты.
```

```text
Сделай 15-секундную анимацию в акварельном стиле на тему моего проекта.
Выбери подходящие техники Lemo, покажи ключевой кадр и собери MP4.
```

```text
Разбери CSV с результатами Reels. Сравни просмотры с обычными результатами
этого аккаунта и отдельно посчитай пересылки на охват. Покажи пропуски.
```

## Локальные проверки

Python 3.10+ и стандартная библиотека достаточны для двух редакционных скриптов.
Команды ниже запускать из `skills/content-studio-ru`.

```bash
python3 scripts/check_text_ru.py script.txt --mode script --wpm 165 --target 30 --json
python3 scripts/check_text_ru.py caption.txt --mode caption --json
python3 scripts/rank_reels.py captured.csv --json
```

Для таблицы нужны как минимум `account` и `views`. Дополнительные поля и условия
сопоставимости описаны в `references/analytics.md`. Пустое значение сохраняется
как пропуск, ноль остаётся нулём. В отчёте указаны источник и размер базы.
Прогноз охватов и определение авторства текста в эти проверки не входят.

## Видео и подключения

Требования к видео определяются выбранным движком: обычно нужны Node.js,
FFmpeg, ffprobe и совместимый браузер. Установка и проверка движков выполняются
отдельно по официальной документации. Облачные сервисы могут быть платными.
Пакет не устанавливает программы автоматически и не содержит API-ключей.

Аккаунты соцсетей, Metricool и платные генераторы пользователь подключает сам.
Секреты, исходные видео и рабочие профили храните в своих проектах. Шрифты,
музыку, изображения и голоса добавляйте с подходящими правами.

## Проверено в этой сборке

Проверены структура навыка, русская обработка текста и расчёты на тестовых
таблицах. Проверка серии MP4 требует FFmpeg/ffprobe. Числа 66 и 15 относятся
к изученным каталогам внешних проектов. Установка этого пакета сама по себе
не подключает соцсети и не предоставляет готовый видеорендерер.

Ошибки и предложения можно присылать через Issues. Для воспроизведения достаточно
версии инструмента, команды и минимального примера с обезличенными данными.
