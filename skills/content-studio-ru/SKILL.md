# Content Studio RU

Вести задачу от материала пользователя до запрошенного результата. Общаться
по-русски, если язык не задан иначе. Использовать данные и оформление текущего
проекта. Сохранять авторские правки и уже выданные разрешения на действия.

## Обязательное правило каруселей

Для карусели читать references/carousels.md. Выдавать каждую страницу отдельным
файлом с отдельным превью/загрузкой: PNG/JPG для статичных слайдов, MP4 для
анимированных. Общая картинка со всеми страницами — только дополнительное превью,
не готовая карусель. Анимацию создавать при соответствующем запросе.

## Рабочий цикл

1. Определить материал, аудиторию, цель, формат и конкретный результат.
   Использовать доступный контекст. Задавать вопросы, существенно влияющие на
   выполнение. При разрешении выбрать самостоятельно продолжать работу.
2. Согласовать новые факты и художественные решения в пределах поручения.
   При готовом брифе выполнять запрошенную работу без дополнительных этапов.
3. Сохранить параметры и версии в рабочей папке проекта. Для нескольких брендов
   вести отдельные профили голоса, оформления и публикаций.
4. Выполнить нужный маршрут. Для готового MP4 создать файл и проверить кадры,
   длительность, звук и соответствие утверждённому тексту.
5. Исправить дефекты. Выдать артефакты в формате пользователя через доступное
   хранение, указать фактические ограничения результата.

## Правила адаптации

- Разделять речь, экранные надписи и описание. Добавлять CTA по цели.
- Основывать кейсы, цитаты, цифры и обещания на данных автора или источниках.
- Выбирать длительность и частоту по материалу. Хуки оценивать редакционно,
  гипотезы проверять по фактическим результатам публикаций.
- Проверять кириллицу, файлы шрифтов, безопасные поля и видимость лица и действий.
  Соблюдать права на материалы и согласованное оформление автора.
- В исходных руководствах брать техники и API. При различиях следовать текущему
  поручению и этим адаптациям. Запрошенный готовый ролик доводить до рендера.
- Сохранять полезные Unicode-символы и составные эмодзи. Замечания к тексту
  оценивать в контексте голоса автора.
- Подключения и функции сервисов проверять перед отправкой. Для публикации
  использовать конкретное поручение пользователя.

## Видеозависимости

Локальные проверки текста и таблиц используют Python 3.10+ и стандартную
библиотеку. Видеомодулям нужны Node.js, браузер и FFmpeg. Использовать уже установленный движок либо подготовить его по официальной
документации, учитывая доступные разрешения среды.
Подробности читать в [environment.md](references/environment.md). Доступность
внешних сервисов устанавливать по текущей среде.
