# Метод анализа

## Источники и время

Фиксировать аккаунт, часовой пояс, время выгрузки, период и точный порядок колонок.
В Metricool список роликов за период обычно означает публикации этих дат с
доступными накопленными показателями на момент выгрузки. Не называть их просмотрами,
полученными именно в этом месяце, без подтверждения семантики источника.
Один снимок не позволяет сравнить первые 7 дней у всех публикаций. Для этого
нужны снимки на одинаковом возрасте. Возраст >=7 дней - лишь проверка чувствительности.

## Очистка

- Проверять URL на дубли. Не считать null нулём.
- Не усреднять процент удержания без определения и знаменателя.
- Не выводить досматриваемость из среднего времени без длительности видео.
- Не считать показатель >3 секунд полным графиком удержания или досмотрами.
- Для дат с >=4 публикациями показывать отдельную описательную группу. Порог -
  аналитическое правило, не свойство Instagram. Публиковать расчёт по всей выборке
  и без этих дат; не удалять неудобные ролики молча.
- Учитывать, что в пакетную дату может попасть обычный ролик; тип Trial не установлен.
- Не делать вывод о «теневом бане», штрафе алгоритма или вреде частоты из одного среза.

## Метрики

| Метрика | Расчёт / смысл |
| --- | --- |
| Относительный результат | Просмотры / медиана сопоставимой группы; указывать базу и n |
| Сохранения на охват | 100 × сохранения / охват; при нулевом/неизвестном охвате не считать |
| Пересылки на охват | 100 × shares / охват; не смешивать shares с отдельной метрикой reposts |
| Удержание >3с | Брать по определению источника, не заменять его другим показателем |
| Среднее время просмотра | Секунды, если это подтверждено источником |
| Прирост аккаунта | Сумма доступных follows gained минус follows lost, с покрытием дней |

Не складывать охваты роликов как уникальных людей. Не приписывать дневной прирост
конкретному ролику, если нет reel-level follows. При расхождении ежедневных gained/lost
с изменением остатка followers указывать расхождение, не подгонять цифры.
Лайки и комментарии не равны заявкам; ноль атрибутированных подписок не равен нулю продаж.

## Вывод и проверка

Для каждого вывода давать факт, объяснение-гипотезу и действие. Не представлять
любую редакционную догадку фактом. Не объявлять коммерческий материал неуспешным,
если есть только его просмотры, а заявок и продаж нет.
Если подписи нет или она не раскрывает тему, помечать «нужен просмотр видео».
По 2 каруселям не заключать, что формат работает или не работает вообще.
Не оценивать эффективность CTA без кликов/диалогов/заявок.

Для эксперимента задавать: одну переменную, сравнимую аудиторию/режим, дату снимка,
основную метрику, достаточную серию повторов. 3-6 роликов - разведка, не строгий тест.
Сравнивать в возрасте 24 часа и 7 дней; соблюдать исходные поручения по публикации.

## Расчёт по CSV или TSV

Передавать уже отобранные сопоставимые ролики в scripts/rank_reels.py. Обязательны
account и views. Рекомендуются url, cohort, reach, shares, saves. cohort обозначает
согласованную группу по формату, периоду и возрасту публикаций. Скрипт не определяет
эти условия самостоятельно. Сохранять исходную выгрузку отдельно от расчёта.

```bash
python3 scripts/rank_reels.py captured.tsv --delimiter tab --json
python3 scripts/rank_reels.py captured.csv --json
```

Если есть внешняя база, указать baseline_median и по возможности baseline_n.
Без неё медиана считается внутри account и cohort по остальным переданным роликам,
исключая текущий. В каждой строке выводятся baseline_source и baseline_n. Выборка
только лучших роликов создаёт смещённую базу, передавать репрезентативную группу.
Небольшую базу использовать как описательное сравнение, без прогноза и причинности.

Передавать полные неотрицательные числа. Для счётчиков допустимы 1200, 1 200,
"1,200" в корректно экранированном CSV. Сокращения 1.2K, 4 млн и дробные счётчики
сначала преобразовать по источнику. Медиана может быть дробной с точкой, например 1.5.
Пустое поле или null означает пропуск, 0 означает измеренный ноль.
Повторяющиеся URL и неверные числа вызывают понятную ошибку вместо скрытой очистки.

Сравнение shares/reach и saves/reach выводится в процентах, без охвата остаётся null.
Подписчики не служат заменой медианы просмотров. При внешней медиане без n это
ограничение явно отмечается. Возраст ролика, даты и источник сохранять в дополнительных
колонках и показывать рядом с выводами. Не смешивать разные определения shares.
