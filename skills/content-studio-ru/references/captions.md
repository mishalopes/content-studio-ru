# Речь → текст → таймкоды → субтитры

## Выбор источника текста

Сначала проверить доступную расшифровку и файлы SRT/JSON пользователя. Не запускать
повторное распознавание без причины. Для аудио/видео без текста выбрать доступный
локальный Whisper/faster-whisper, Remotion Whisper WebGPU или коннектор
транскрипции, например AccurateScribe. Наличие инструкции не означает наличия
модели, GPU или авторизации. Проверить зависимости до обещания результата.
Облачную обработку выполнять в рамках поручения и возможностей сервиса.

Для Remotion изученный вариант использует @remotion/whisper-webgpu.
Официальная инструкция: https://www.remotion.dev/docs/whisper-webgpu/transcribe
Для русского выбирать многоязычную модель, например small, и явно русский язык
по API установленной версии. Модель small.en предназначена для английского.
Проверить canUseWhisperWebGpu(); при отсутствии совместимого GPU выбрать доступный
другой движок. Модели скачиваются отдельно; в пакет они не входят.

## Распознать и исправить

Распознавать каждый оригинальный файл отдельно. Сохранить исходную расшифровку,
язык, движок, модель и таймкоды относительно начала этого файла. Для спорных слов
прослушать фрагмент, проверить имена, термины, числа, отрицания и переключения
языков. Не додумывать неразборчивую речь; отметить спорный участок.
Исправление орфографии не должно менять сказанный смысл. Экранный пересказ
и дословную дорожку хранить отдельно.

Для пословной анимации нужны пословные интервалы. Если движок выдаёт только
фразы, не выдавать равномерное деление фразы на слова за измеренные таймкоды.
Для точной синхронизации использовать пословное распознавание или выравнивание
текста по аудио. Проверить дрейф в начале, середине и конце.

## Единый формат

Хранить массив объектов Caption:

```json
[
  {"text":"Привет", "startMs":0, "endMs":400, "timestampMs":200, "confidence":null},
  {"text":" всем!", "startMs":400, "endMs":950, "timestampMs":650, "confidence":null}
]
```

Время в миллисекундах. Начало неотрицательно, конец позже начала, значения конечны.
Сохранить пробелы в text: они нужны для соединения слов. timestampMs и confidence
допускают null; неизвестную уверенность не подменять числом. Дорожки нескольких
говорящих хранить раздельно при необходимости перекрытия речи.

Локальная проверка и экспорт:

```bash
python3 scripts/captions_io.py captions.json --duration-ms 15000 --srt captions.srt
```

Скрипт проверяет JSON и интервалы, экспортирует каждую входную запись отдельным
SRT-блоком. Он не распознаёт звук и не объединяет слова в читабельные фразы.
Для пословного JSON сначала подготовить отдельную версию с группировкой по фразам
для SRT; исходные словесные таймкоды сохранить для подсветки.

## После монтажа

Хранить таблицу сегментов: source, sourceInMs, sourceOutMs, timelineStartMs, speed.
Для исходного времени t: t_итог = timelineStartMs + (t - sourceInMs) / speed.
Пересекать интервал субтитра с выбранным фрагментом до преобразования.
Не переносить субтитры удалённых участков. При перестановке кадров переносить
видео и соответствующий текст вместе; изменение скорости должно менять оба.

В Remotion держать клип и субтитры в общей группе Sequence/Series.Sequence,
с общей обрезкой и playbackRate по поддерживаемому API версии проекта.
Если нужен редактор Caption Editor, использовать доступный ему inline-массив
в BasicCaptions; проверить это в фактическом Studio. Не считать обычный импорт
JSON автоматически редактируемым через все UI.
Документация: https://www.remotion.dev/docs/captions

## Дизайн и контроль

Разбить на смысловые фразы, обычно 1–2 строки. Позицию задавать по референсу и
интерфейсу площадки, не фиксировать текст у самого нижнего края. Проверить
контраст, переносы, кириллицу, лицо, важные действия и время чтения.
При karaoke подсветке сверять ударения с записью; не заменять смысл мельканием.
Проверить контрольные кадры и полный ролик со звуком, затем экспортировать MP4
и SRT/JSON по задаче. Наличие корректного JSON не доказывает точность ASR.
