# Подключения и ключи

Навык содержит инструкции и локальные проверки; он не предоставляет аккаунты,
подписки, API-квоты и ключи. Сначала использовать уже авторизованный коннектор
нужного сервиса. Наличие коннектора не считать подтверждением нужного тарифа
или работоспособности конкретной операции.

Для API использовать штатное подключение провайдера, секреты среды или локальное
приватное хранилище проекта. В публичных примерах указывать только имена переменных
и пустые значения; фактические ключи, cookies, токены, URL с авторизацией и .env
не помещать в README, исходники, логи, скриншоты и результаты рендера.
Не предлагать обход авторизации и не извлекать учётные данные из браузера.

Локальное видео Remotion/FFmpeg обычно не требует облачного API-ключа; облачный
рендер, TTS, генерация и планировщик могут требовать отдельную авторизацию,
оплату и настройки. Проверять это под выбранный маршрут. Лицензионный ключ
программы и ключ API облачного сервиса — разные сущности.

При публикации проверить аккаунт, медиа, подпись, обложку, дату и часовой пояс;
после записи прочитать очередь. Подробности в publishing.md. Подключения автора
публичного пакета не передаются пользователям, которые установили навык.
