# Сценарии и подписи

Выбирать одну мысль и понятный результат для зрителя. Для нового начала предложить
при необходимости три разных приёма из hooks-ru.md по доступным фактам.
Для демонстрации планировать слышимый или видимый результат. Историю строить
вокруг реального события. Сохранять удачные формулировки автора.

Для каждой части фиксировать речь, экранную надпись и действие. В подписи
добавлять контекст, нюанс или шутку. Числа, личный опыт и кейсы подтверждать.
Исследовательские заметки хранить отдельно от публикационного текста, если
пользователь не попросил включить источники в публикацию.

Проверять по одной смысловой реплике на строку

```bash
python3 scripts/check_text_ru.py script.txt --mode script --wpm 165 --target 30 --json
python3 scripts/check_text_ru.py hook.txt --mode hook --json
python3 scripts/check_text_ru.py caption.txt --mode caption --json
```

Темп 165 слов в минуту использовать как исходную оценку. При наличии записи
измерить реальный темп автора. Паузы, музыка и демонстрации увеличивают длительность.
Предпросмотр первых 125 символов условный. Лимит подписи задавать через
--caption-limit после проверки правил площадки при необходимости.

Скрипт распознаёт русский текст и хештеги, печатает замечания и временные
оценки. Текст редактировать по смыслу и голосу автора. Обход детекторов и прогноз
охвата в задачи этой проверки не входят.
