# Окружение

Для check_text_ru.py и rank_reels.py нужен Python 3.10+ и стандартная библиотека.
Для validate_batch.py дополнительно нужны FFmpeg и ffprobe.
Видеорендер зависит от выбранного движка: проверить Node.js, npm, браузер,
FFmpeg, версии и совместимость по официальной документации.

Внешние движки устанавливаются отдельно; пакет не содержит загрузчиков,
браузеров, моделей, шрифтов и сторонних исполняемых модулей. Использовать
инструкции из engines.md и remotion.md. Сохранять зависимости и lock-файл
в отдельном проекте. Не обещать поддержку ОС без фактической проверки.

Для облачных сервисов использовать штатную авторизацию и доступные коннекторы.
При недоступном движке сообщить точную причину и выполнить доступную подготовку.
Приватные настройки и ключи хранить средствами среды, отдельно от публичного пакета.
