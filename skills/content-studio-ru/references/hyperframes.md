# HyperFrames: HTML-монтаж и анимация

Использовать выбранную версию проекта и её CLI. Если движок ещё не установлен,
следовать официальному источнику https://github.com/heygen-com/hyperframes.
Внешний код и установщик в пакет не включены. Команды ниже относятся к изученному
CLI 0.8.216; перед применением другой версии проверить --help.

## Проект и временная модель

Корневая композиция index.html содержит длительность и сцены; медиа и файлы
шрифтов хранить локально в assets/. Для сцен делать отдельные композиции,
стабильные id и читаемые переменные текста, цвета и источников.
Timed-элемент обозначать class="clip", data-start и data-duration в секундах.
Интервал показа полуоткрытый: начало включено, конец исключён. Порядок слоёв
определять z-index; индекс трека не заменяет порядок отрисовки.

Создать paused-таймлайн и зарегистрировать в window.__timelines под id композиции.
Результат должен зависеть от запрошенного времени: без Date.now(), случайности
без seed и сетевой загрузки во время покадрового рендера. Анимировать дочерний
элемент clip, не управлять видимостью самого clip через конфликтующие tween.
Не смешивать CSS transform и GSAP transform на одном объекте.

Для видео явно определить сохранение звука или muted; музыку и J/L-переходы
выносить в отдельные аудиоклипы. У каждого audio должен быть id. Не управлять
проигрыванием медиа вручную параллельно движку. Относительные пути assets/ должны
разрешаться и в подкомпозициях. Дождаться готовности шрифтов и изображений.

## Рабочий цикл

В подготовленном проекте использовать его wrapper, если он есть; иначе CLI:

```bash
npx hyperframes timeline --json
npx hyperframes lint
npx hyperframes check --json
npx hyperframes snapshot --at 0,2,5
npx hyperframes preview --background
npx hyperframes render --quality delivery --output out.mp4
```

Время snapshot заменить кадрами своего проекта. Ошибки check исправить;
пустой отчёт или ноль проверенных образцов не считать проверкой качества.
Просмотреть середину каждой сцены и обе стороны перехода. Для готового MP4
проверить длительность, звук, декодирование и соответствие таймлайну.

Каталог catalog использовать для поиска готовых техник; доступность и лицензию
ресурсов проверять отдельно. Не публиковать проект и диагностические исходники
в облако/Issues как побочный эффект рендера. Публичную публикацию выполнять
только по соответствующему поручению. HeyGen-аватары и платные API не подключаются
автоматически от установки этих инструкций.

## Перенос из других инструментов

Выбрать уровень: нативные HTML/GSAP элементы; размещённый Canvas/Three.js/Lottie
с управлением временем; либо готовое видео из Blender/другого редактора.
Указать, что осталось редактируемым. При переносе Remotion перевести кадры
в секунды через fps, проверить пути, шрифты, easing и тайминг. Сравнить кадры
оригинала и переноса на одинаковых временах; записать отличия.
