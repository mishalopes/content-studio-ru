Для японской рисованной анимации начать с cel-anime-80s; для акварели — watercolor;
для бумажного объёма — paper-popup; для винтажного мультфильма — midcentury-toon
или rubber-hose; для объёмного продукта — glass-product. Это разные визуальные
методы, а не набор кнопок для любого генератора. Реалистичный персонаж требует
отдельного решения по моделям/рендеру; каталог не гарантирует такой результат.

Для нового стиля заполнить карточку из motion-design.md и сделать тестовую сцену.
