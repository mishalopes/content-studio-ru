# Публикация

Использовать доступный коннектор площадки или планировщика. Проверить аккаунт,
часовой пояс, формат и актуальные функции. Владелец предоставляет авторизацию
своему аккаунту через штатный механизм сервиса.

По поручению пользователя подготовить медиа, подпись, обложку и время.
Относительное время считать от текущего момента с явным часовым поясом.
Сохранять утверждённый текст. Пустую подпись использовать по поручению
или явно сообщить о выборе, если пользователь попросил только загрузить файл.

Для Metricool прочитать текущую схему инструментов и настройки бренда.
Передавать локальные файлы через файловые аргументы коннектора. Различать видео
и обложку, проверить итоговые media и thumbnail. Если обложке требуется отдельная
загрузка и обновление, использовать доступный процесс. Не помещать JPG как
второе медиа в финальный Reel.

После записи проверить статус, аккаунт, текст, медиа, обложку и дату.
ID и ссылку планировщика сохранять в приватном проекте. При неизвестном результате
сначала проверить очередь. Изменять публикацию по свежей записи, учитывая
возможную смену ID при сохранении.

Планирование и выход сообщать по соответствующему подтверждённому статусу.
Direct, стикеры, музыку и коллаборации проверять по доступным инструментам.
Для внешней программы использовать её авторизацию и актуальные условия API.
