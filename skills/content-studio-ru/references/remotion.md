# Remotion

Официальные инструкции: https://github.com/remotion-dev/skills
Документация движка: https://www.remotion.dev/docs
Открывать нужный раздел под задачу; исходники движка и его навыки в пакет не входят.

В существующем проекте определить версию по package.json и lock-файлу.
Для новой функции сверить API с официальной документацией соответствующей версии.
Для нового проекта подобрать совместимые зависимости, сохранить версии и lock-файл.
Следовать запросу пользователя на превью или готовый файл.

Типовые команды для подготовленного проекта

```bash
npx remotion studio --no-open
npx remotion compositions src/index.ts
npx remotion still src/index.ts Main out/cover.png --frame=30
npx remotion render src/index.ts Main out/reel.mp4 --codec=h264
```

Пути и ID Main заменить реальными значениями. После сборки проверить субтитры,
синхронность, кириллицу, медиа и кадры на границах сцен. Инструкции Remotion
распространяются под MIT. Лицензирование видеодвижка и сервисов проверять
по https://www.remotion.dev/docs/license.


## Структура и анимация

Зафиксировать width, height, fps и durationInFrames композиции. Рассчитывать
движение из useCurrentFrame()/fps; interpolate и spring применять с явными
интервалами и ограничениями. Не использовать случайность без seed, системные
часы или эффект React как единственный источник анимации. Проверить произвольный
кадр без предварительного проигрывания всей сцены.

Сцены разделять Sequence/Series, медиа и субтитры группировать по исходнику.
Для переходов учитывать фактическое перекрытие, чтобы итоговая длительность
соответствовала таймлайну. Дождаться готовности изображений, видео и шрифтов.
Поддерживать единые совместимые версии пакетов Remotion и lock-файл.

## Дополнительные маршруты

| Задача | Что определить и проверить |
| --- | --- |
| Субтитры | captions.md: ASR, исходные таймкоды, обрезка, скорость, оформление |
| Медиа | Метаданные, кроп, поворот, trim, playbackRate, звук и пути |
| Карты | Координаты/GeoJSON, проекция, атрибуция тайлов, камера и ключ провайдера |
| Studio | Локальный URL, загрузка композиции, возможность редактирования props |
| Параметрические серии | Схема входных данных, уникальные ID, проверка каждой версии |
| Облачный рендер / SaaS | Авторизация, цена, хранилище, очереди, лимиты и обработка ошибок |
| Обновление версии | Совместимость API и пакетов, контрольные кадры до и после |

Для карт не придумывать координаты реального места. Для облачного рендера
не переносить локальные пути как доступные серверу URL. Ключи подключать по
connections.md. Локальная установка Remotion не подключает AWS, провайдера карт
или TTS. Перед использованием нового API открыть официальный раздел документации
версии проекта. Не считать наличие маршрута поставкой всех внешних библиотек.
