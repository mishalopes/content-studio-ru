# Монтаж и выбор движка

Для существующего проекта использовать его технологию, если она решает задачу.
Для нового выбрать подходящий инструмент по материалу и доступной среде.

| Задача | Подход |
| --- | --- |
| Простые обрезки и звук | FFmpeg или имеющийся редактор |
| React, параметрические сцены, серии | Remotion |
| HTML-композиция, титры, веб-анимация | HyperFrames |
| Фильм, стилизованная анимация | Lemo Opuscar |
| Заставка, типографика, графическая техника | MG Styles 15 |

Проверить длительность, разрешение, поворот, частоту кадров и дорожки исходника
через ffprobe. Просмотреть кадры и доступное аудио. При отсутствии возможности
прослушивания описать проверенное и использовать доступную расшифровку с учётом
её точности. Составить монтаж по мысли и действию.

Для говорящей головы менять крупность и положение по смыслу. Использовать
приближение, удаление, детали и дополнительные кадры. Проверять читаемость
текста, сохранность лица, рук и важных действий.

Таймлайн делать воспроизводимым при переходе к любому кадру. Фиксировать время
начала, длительность, текст и медиа. Для анимации сохранять согласованных
персонажей, пространство, палитру и последовательность событий.

Для MP4 использовать H.264, yuv420p и AAC, если площадка или пользователь
не требует иного. Проверить ffprobe, декодирование и кадры начала, середины,
конца и переходов. Для речи проверить громкость и клиппинг. Исправления
подтверждать проверкой итогового файла.
